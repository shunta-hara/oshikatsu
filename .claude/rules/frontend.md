# フロントエンドルール（frontend/, React + TypeScript）

## 型
- `any` を使わない。外部由来の値（API レスポンス・フォーム入力）は zod などでバリデーションしてから型を確定させる
- 型は `frontend/src/types/` に集約する。コンポーネントファイル内で独自に重複定義しない

## コンポーネント
- 1ファイル1コンポーネントを原則とする
- ロジック（API呼び出し・状態管理）とビュー（JSX）を分離する。API呼び出しは `frontend/src/api/` 配下のフックか関数にまとめる
- Props は明示的に型定義する（`React.FC` の暗黙 any props に頼らない）

## API通信
- backend の OpenAPI 定義から生成した型 or 手動定義した型を使い、レスポンス形状を型安全に扱う
- fetch/axios のエラーハンドリングを省略しない（失敗時のUI状態を必ず用意する）

## スタイル
- 既存のディレクトリ構成・命名規則に合わせる（新しい規約を勝手に持ち込まない）
