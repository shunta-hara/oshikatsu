# 収集バッチルール（collector/, Python）

## 型・スタイル
- 関数・メソッドには型ヒントを必ず付ける
- フォーマットは black、静的チェックは可能であれば mypy/ruff を使う

## スクレイピング/外部API呼び出し
- HTTP リクエストには必ずタイムアウトを設定する
- 一時的な失敗（ネットワークエラー・429/5xx）はリトライ（指数バックオフ推奨）する。無限リトライはしない
- 収集先サイトの利用規約・robots.txt を尊重する。過度な高頻度アクセスをしない
- 取得したニュース・番組情報は日時・出典URLを必ず保持する（後から出典を追跡できるようにする）

## backend との連携
- DB への書き込み方式（直接DB書き込み or backend内部API経由）は `docs/` に記録された方針に従う。独自に変更しない

## ロギング
- 収集ジョブの成功/失敗・件数を必ずログ出力する（サイレント失敗を避ける）
